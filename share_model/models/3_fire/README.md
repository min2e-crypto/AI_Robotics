# 3번 모델: 화재(불꽃·연기) 탐지 — **임시 버전 (dfire_v1)**

| 항목 | 값 |
|---|---|
| 파일 | `best.pt` (실행 이름 `dfire_v1`) |
| 모델 | YOLO26s, 입력 크기 640 |
| 클래스 | `fire` = 0 (불꽃), `smoke` = 1 (연기) |
| 학습 데이터 | D-Fire 21,527장 (**대부분 지상 시점**) + VisDrone 드론 사진을 "화재 없음" 이미지로 섞음 |
| 확신도 기준 | 0.25 (임시. 정식으로 정하지 않음) |

## 성능

| 구분 | 값 |
|---|---|
| D-Fire 공식 test | mAP50 0.791 / mAP50-95 0.462, 불꽃 Recall 0.678, 연기 Recall 0.807 |
| val | mAP50 0.672 (test가 val보다 0.12 높은 이유는 확실하지 않음) |
| 항공 시점 "화재 없음" 사진 오탐률 | 0.7% (확신도 0.25) |
| 항공 시점에서 **진짜 불을 잡는지** | **잴 데이터가 없어 모름 — 가장 큰 위험** |

- 다른 후보 `dfire_v2_960`(입력 960)은 val mAP50 0.692로 조금 높지만 추론이 약 3배 느림. 두 모델 중 선택은 아직 안 함.

## 알려진 약점

1. **밤의 따뜻한 조명을 불로 잡음:** 건물 조명, 창문, 가로등 번짐, 빨간 후미등. 항공 오탐 불 8장 전부가 이 유형.
2. **실제 CCTV 사고 사진에서 전조등·후미등을 불로 잡음** (확신도 0.27, 0.48).
3. **연기 오탐:** 낡은 흰 지붕, 회색 노면, 전조등 불빛·배기 김.
4. 빨간 차를 불로 잡은 경우는 지금까지 없음.

→ 그래서 재강 쪽 시험에서는 "불 옆 차가 파손·전복일 때만 화재로 보고, 정상 차 옆의 불이나 연기는 관제자 확인으로만 넘긴다"는 규칙을 정했다 (`../../정해둔_규칙.md`).
