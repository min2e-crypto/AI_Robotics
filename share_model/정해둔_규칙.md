# (참고) 사고 범위 계산에 쓰려고 정해 둔 규칙

재강이 `vision.py` 결과로 사고 범위(Zone)를 계산하는 코드를 만들어 시험하면서 정한 것들이다 (2026-11-12).
범위 계산은 팀원이 새로 만들 예정이므로 **강제 사항이 아니라 참고용**이다. 다르게 하려면 재강과 이야기해서 바꾼다.

## 1. 사고 후보와 묶기

| 항목 | 정한 것 | 이유 |
|---|---|---|
| 사고 후보 | 파손·전복 판정 차량, 불(fire) 근처 차량 | 구현 계획 6절 |
| 애매(`uncertain`) 차량 | 후보로 올리지 않고 관제자 확인 목록에 넣음. 범위 안에 있으면 표시 | 모델이 자신 없는 판정을 자동으로 쓰지 않기 위해 |
| 같은 사고 건 | 후보끼리 거리 ≤ 큰 차 길이 × 1.0 | |
| 맞닿은 차 묶기 | 사고 차와 맞닿은 차(거리 ≤ 짧은 차 길이 × 0.1)는 상태와 상관없이 묶음. **한 단계만** | 정체가 심한 사진에서도 줄줄이 묶이지 않는 것을 확인함 |
| 사고 형태 | 화재 > 전복 > 파손 | 구현 계획 6절 |
| 사고가 여러 건 | 관제자가 대상 선택 | |

## 2. 불·연기

| 항목 | 정한 것 | 이유 |
|---|---|---|
| **연기** | 사고 후보·화재 형태에 **반영하지 않고 관제자 확인으로만** | 연기 오탐(흰 지붕·회색 노면)과 충돌 먼지 때문. 느슨한 연기 박스 하나가 옆 전복 사고까지 "화재"로 올린 사례 |
| **불 + 정상 차** | 화재 범위를 만들지 않고 **관제자 확인으로만** | 전조등·후미등을 불로 잡아 화면 전체가 화재 범위가 된 사례 (2장). 로봇의 장점은 사고를 빨리 찾는 게 아니라 외부 차량 통제와 현장 처리를 동시에 하는 것이라, 관제자 확인으로 늦어져도 괜찮다고 판단 |
| 불 + 파손·전복 차 | 화재 범위 | |
| 불 근처 기준 | 불 박스와 차 박스 거리 ≤ 차 길이 × 1.0 | |

## 3. 범위 크기 (여유 거리)

| 사고 형태 | 여유 (범위 사방에) | 근거 |
|---|---|---|
| 파손 | 차 길이 × 0.5 (승용차면 약 2.35m) | 시연 파라미터. 법적 근거 없음 |
| 전복 | 차 길이 × 0.5 (파손과 같게) | 같음 |
| 화재 | **15m** | 국내 법령에는 거리 기준이 없음 (소방기본법 23조: 소방대장이 현장에서 정함). NTSB·NFPA·NHTSA의 **손상 전기차 보관 간격 50ft(약 15m)**를 빌려 씀. 발표 때 "도로 현장 법정 기준이 아님"을 밝힐 것. 시연은 모형 축척에 맞춰 줄여야 함 |

- 여유를 옆 방향에도 똑같이 주면 화재는 사실상 전 차로 통제가 된다. 진행 방향과 옆 방향을 나눌지는 **미결**.

## 4. 도로 좌표로 바꿀 때 (재강 시험에서 배운 것)

- **박스 네 모서리를 바닥으로 보면 안 된다.** 비스듬한 카메라에서는 박스 위쪽이 차 지붕이라, 바닥에 투영하면 승용차 길이가 6~31m로 나왔다.
- 대신 **박스 아랫변 가운데 점 = 차가 땅에 닿은 가장 가까운 점**으로 보고, 거기서 카메라 반대쪽으로 **표준 크기 사각형**을 놓았다.
  - 승용차 4.7 × 1.9m (국내 설계기준 소형자동차 길이 4.7m), 승합 5.2 × 2.0, 트럭 9.0 × 2.5 (트럭은 1톤~대형 차이가 커서 가장 애매), 버스 12 × 2.5 — 모두 임시값
  - **파손·전복 차는 방향을 모르므로 4.7 × 4.7m 정사각형**으로 봄 (가로로 누운 승합차 사례)
- 시험 결과 (CCTV 사진 4장, 범위가 차를 완전히 덮으면 통과): 위에서 내려다본 사진 2장 통과, 비스듬한 사진 2장 실패 (0.5m, 약 2m 벗어남).
  - 실패 원인은 계산 방식보다 **1번 박스 아랫변 위치 오차**와 **매우 낮은 카메라 각도**. 시연 카메라를 위에서 내려다보게 달면 줄어들 것으로 예상 (확인은 안 됨).
- 보정 방법: 사진에서 크기를 아는 직사각형(차로 폭 × 점선 한 주기)의 네 꼭짓점을 클릭해 호모그래피를 구함.
  - 국내 고속도로 차로 폭 3.5~3.6m, 점선 도색 8m + 빈 길이 12m(2015년 논문 기준, **현행 기준은 확인 필요**).
